# AI Prompts Used

## Prompt 1 — Generate Login Tests

Generate Playwright test cases in JavaScript for Login module including:

- Valid login
- Invalid username
- Invalid password
- Empty fields
- SQL injection attempt
- Forgot password navigation

Use Page Object Model structure.

## Prompt 4 — AI Failure Explainer

Create reusable AI helper module:

- Connect to Gemini API
- Function: explainFailure(errorMessage)
- Explain test failures in QA language
- Provide root cause and suggested fix
- Integrate into test.afterEach hook
